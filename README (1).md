# Ατζέντα Ειδήσεων ανά Κατηγορία (ΑΠΕ-ΜΠΕ, 2016–2026)

Streamlit εφαρμογή (θέμα 14β): γράφεις έναν όρο → μηνιαίο γράφημα άρθρων ανά κατηγορία → κορυφώσεις → σύνοψη «γιατί κορυφώνεται» με λέξεις-κλειδιά και δείγμα τίτλων με συνδέσμους.
Dataset: [glossAPI/amna-press](https://huggingface.co/datasets/glossAPI/amna-press) (CC BY-NC-ND 4.0, δικαιώματα ΑΠΕ-ΜΠΕ).

- Εφαρμογή: https://amna-agenda-bill.streamlit.app/
- Αξιολόγηση (24 περιπτώσεις): `evaluation.csv` / `evaluation.xlsx`
- Βασικά prompts προς τον agent: `PROMPTS.md`

## Οδηγός χρήσης
1. Γράψε τον όρο στο πεδίο «Όρος αναζήτησης» (π.χ. εκλογές, πυρκαγιά, πανδημία). Αν γράψεις πολλές λέξεις, πρέπει να υπάρχουν όλες στον τίτλο ή στα tags.
2. Από το πλαϊνό μενού ρύθμισε έτη, ευαισθησία κορυφώσεων k (τοπικό μέγιστο ≥ μέσος όρος + k·σ), ελάχιστα άρθρα, μέγιστο πλήθος κορυφώσεων και κατηγορίες.
3. Δες το στοιβαγμένο γράφημα και την καρτέλα «Κορυφώσεις ανά κατηγορία», τον πίνακα «Κορυφώσεις του όρου» και πάτησε «Δημιουργία σύνοψης για τις κορυφώσεις».
4. Η σύνοψη με LLM (Anthropic) είναι προαιρετική και χρειάζεται API key· χωρίς key εμφανίζονται λέξεις-κλειδιά.

## Εκτέλεση τοπικά
```bash
pip install -r requirements.txt
python prepare_data.py          # 1 φορά· κατεβάζει το dataset (~1,5 GB) και παράγει data/amna_slim.parquet (312.950 άρθρα, 31 MB)
streamlit run app.py
```

## Αρχεία
- `app.py`: η εφαρμογή (κανονικοποίηση ελληνικών, απλό στέλεχος λέξης, μηνιαίοι μετρητές, ανίχνευση κορυφώσεων, σύνοψη).
- `prepare_data.py`: λήψη και φιλτράρισμα του dataset (από 1/1/2016, στήλες id, category, title, created, tags, url).
- `evaluation.csv`, `evaluation.xlsx`: βαθμολόγηση 24 κορυφώσεων με εξωτερικές πηγές.
- `PROMPTS.md`: τα βασικά prompts.
